Ponto Crítico

Aviso de Segurança

🚨 Risco: Skills de fontes desconhecidas

O treinamento mostra o Claude baixando automaticamente 5 skills da internet. Isso parece prático — e é — mas tem risco real em produção.

Deixar a IA baixar arquivos .md ou scripts aleatórios da web para rodar no terminal local pode abrir brechas para injeção de prompts maliciosos.
Scripts com acesso ao .env podem vazar credenciais, tokens de API, chaves de banco e segredos de cliente.
Oriente os alunos: sempre inspecione o código das skills antes de usá-las. Prefira repositórios verificados (GitHub oficial da Anthropic, fontes de equipe interna).
