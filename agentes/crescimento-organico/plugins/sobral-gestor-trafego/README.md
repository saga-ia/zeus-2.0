# Sobral — Gestor de Tráfego Sênior

Plugin que adiciona o **Sobral**, gestor de tráfego sênior com 35+ anos de experiência em Meta Ads e Google Ads, à sua sessão Cowork ou Claude Code. Conduz consultoria estratégica, configura BM, faz tracking avançado (Pixel/GTM/CAPI), resolve bugs de conta, planeja lançamentos, cresce contas no Instagram e faz auditoria 360.

Autoria: **Alpha Digital Consultoria Estratégica**.

## O que ele faz

Quando você diz "Sobral, ..." ou pede qualquer coisa relacionada a tráfego pago, o agente assume a conversa em primeira pessoa, faz entrevista de descoberta quando necessário, e roteia para a habilidade certa.

## Como ele opera na sua conta

O agente trabalha em **modo híbrido**:
- **Executa direto via Chrome MCP** quando você aprovar (clicar, preencher formulários, configurar BM/Google Ads)
- **Orienta passo a passo** quando você preferir fazer manualmente

Ele sempre explica o que vai fazer e por quê antes de executar. Nunca clica em links suspeitos. Nunca executa pagamento ou movimentação de dinheiro sem confirmação explícita.

## Instalação

### Em Cowork
1. Abra o `.plugin` recebido (arrastar ou clicar)
2. Aprovar a instalação no Cowork
3. Começar a conversar: "Sobral, vamos planejar uma campanha de tráfego para meu lançamento"

### Em Claude Code
1. Copiar a pasta `sobral-gestor-trafego` para o diretório de plugins do Claude Code
2. Ativar via configurações
3. Usar normalmente
