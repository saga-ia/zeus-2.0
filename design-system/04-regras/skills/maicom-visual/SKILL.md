# Maicom — Skill 07: Identidade Visual e Paleta

**Fase 2 (Estratégia). Pré-requisito: Skills 04 e 05 completas.**

> Esta skill entrega **briefing estratégico**, não arquivos de design. A execução gráfica é responsabilidade da equipe de design a partir deste documento.

## Ativar quando
- Skills 04 e 05 estão completas.
- Frases-gatilho: "define a identidade visual", "qual é a paleta", "como deve ser o feed", "brief para o designer".
- Visual atual em conflito com posicionamento.
- Rebranding ou atualização de identidade.
- Designer novo precisando de briefing.

## Não ativar quando
- Skills 04 e 05 ainda não estão prontas. **Visual sem posicionamento e tom é decoração.**

## Entrega: brief estratégico visual em 8 blocos

### Bloco 1 — Diagnóstico visual atual
- O que o visual atual comunica (em uma frase).
- O que ele **deveria** comunicar (em uma frase).
- Gaps específicos (cor demais / pouco contraste / tipografia errada / inconsistência entre peças).
- O que **manter** (elemento que já funciona).
- O que **descartar** (elemento que prejudica).

### Bloco 2 — Direcionamento estratégico
- **Sensação que o visual deve transmitir** (3-5 adjetivos calibrados: ex: "sóbrio, confiante, técnico, com toque humano, sem rigidez corporativa").
- **Nível de formalidade** (formal / semi-formal / casual / despojado).
- **Mercado de referência** (de que segmentos visuais buscar inspiração: ex: "private banking + tech startup, evitar visual de coach").
- **Posição entre extremos** (clean vs maximalista / sério vs lúdico / clássico vs contemporâneo).

### Bloco 3 — Paleta de cores
Estrutura completa:

| Função | Cor | Hex | Uso |
|---|---|---|---|
| Primária | [nome] | #XXXXXX | Identidade, fundo dominante |
| Secundária | [nome] | #XXXXXX | Apoio, segundo plano |
| Accent | [nome] | #XXXXXX | CTAs, destaques, números importantes |
| Neutro escuro | [nome] | #XXXXXX | Texto principal |
| Neutro claro | [nome] | #XXXXXX | Fundo, espaço |

**Regras de uso:**
- Percentual aproximado de cada cor no feed (ex: 60% primária / 25% neutros / 10% secundária / 5% accent).
- Combinações proibidas (cores que não devem aparecer juntas).
- Variações pra modo claro/escuro (se aplicável).
- Justificativa psicológica de cada escolha (por que essa cor reforça o posicionamento).

### Bloco 4 — Tipografia
- **Tipografia principal** (display, manchetes): nome + peso + uso.
- **Tipografia de texto** (corpo): nome + peso + uso.
- **Hierarquia** (tamanhos relativos: H1, H2, body, caption).
- **Regras:** quando misturar pesos, quando usar caixa alta, quando itálico, quando sublinhado.
- **Fontes proibidas** (Comic Sans é óbvio, mas listar específicas do nicho que viraram clichê).

### Bloco 5 — Estética visual
- **Estilo de imagem:** fotografia natural / fotografia produzida / ilustração / 3D / mix.
- **Tratamento:** filtros, granulado, saturação, dominante de cor.
- **Elementos gráficos recorrentes:** formas, ícones, padrões, texturas.
- **Estilo de carrossel:** capa com hook / capa com número / capa com pergunta. Estrutura interna.
- **Estilo de Reel/Short:** dinâmica de cortes, uso de legendas, b-rolls, posição do criador no quadro.

### Bloco 6 — Aplicação por plataforma

**Instagram (Feed):** padrão do grid (alternância de cores? blocos de 9?), tipo de capa por pilar de conteúdo.

**Instagram (Stories):** templates fixos (fundo, posição do logo, regiões de texto).

**Instagram (Reels):** thumbnail style, legenda dominante, lower thirds.

**LinkedIn:** capa de post, capa de artigo, foto de perfil otimizada.

**YouTube:** thumbnail (composição, posição do rosto, contraste, palavra-chave grande), banner, end card.

**Site/LP:** hero section, paleta aplicada, hierarquia visual.

### Bloco 7 — Referências visuais organizadas
- **Referências diretas** (perfis/marcas a se aproximar visualmente, com link e justificativa).
- **Referências de afastamento** (visuais a evitar mesmo quando funcionam, com justificativa de por que não cabem aqui).
- **Moodboard sugerido** (descrição em texto de 5-10 imagens que comporiam o moodboard).

### Bloco 8 — Brief executivo final para o designer
Resumo de 1 página que o designer recebe pra começar a executar. Estrutura:

```
PROJETO: [nome do cliente]
POSICIONAMENTO: [frase única da Skill 04]
TOM DE VOZ: [resumo do arquétipo da Skill 05]

PALETA: [5 cores com hex]
TIPOGRAFIA: [2 fontes com peso]
SENSAÇÃO: [3-5 adjetivos]
EVITAR: [3-5 elementos]

ENTREGA INICIAL ESPERADA:
1. [item específico]
2. [item específico]
3. [item específico]

REFERÊNCIAS: [links]
PRAZO: [data]
APROVADOR: [Jeff via fila Vermelha]
```

## Regra crítica
Esta skill entrega briefing estratégico, **não arquivos de design**. A execução gráfica é da equipe de design a partir deste documento. Se a equipe ler o brief e ainda não souber começar, **o brief não está pronto** — refazer com mais especificidade.
